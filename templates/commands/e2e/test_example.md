# E2E Test: Example (replace me)

One file per scenario in this directory. Keep steps short and observable. Mark assertions with **Verify**.

## User Story
As a user
I want to open the home page
So that I know the application is running

## Test Steps
1. Navigate to the `Application URL`
2. Take a screenshot of the initial state
3. **Verify** the page has a visible title
4. **Verify** no error banner is shown

## Success Criteria
- The page loads
- 1 screenshot is taken
